# 研究方案 v2：诊断 → 修复 → 训练（2026-09-25）

**总问题：** 大模型执行一条可计算的临床规则时，会在哪些环节出错？这些错误能不能从答案表面看出来？哪种手段能修好哪种错误？

三篇论文共用一个测试台：**病人档案 × 已发表的风险公式和指南阈值 → 由程序算出的标准答案**。心血管风险只是试验台，研究对象是大模型本身。

| 论文 | 回答什么 | 依赖 |
|---|---|---|
| **P1 诊断** | 模型在「选规则、算风险、下结论、判断能否下结论、说到做到」各环节的错误率，以及它们随模型大小怎么变 | 测试台 |
| **P2 干预阶梯** | 从便宜到昂贵的各种修法，各修好了哪类错误、代价多大、换一批病人或换一种写法后还剩多少 | P1 的错误分类 |
| **P3 强化学习** | 用程序给分训练本地小模型，能否比 P2 最好的修法修得更彻底；学到的是能力还是格式 | P2 的最佳修法作对照 |

文中所有「预期结果」都是**假设**，写明了每种结果各自说明什么。反过来的结果同样可以发表。

## 变更记录：与 v1（`proposal_A_B_C_2026-09-23.md`）的区别

| | v1 | v2 |
|---|---|---|
| 组织方式 | 按现象分：A 规则更新、B 信息不全、C 强化学习，三篇各自独立 | 按研究流程分：诊断 → 修复 → 训练，三篇前后衔接 |
| A（规则更新） | 独立成篇（论文 1） | 并入 P1，作为诊断的一个维度 |
| B（信息不全） | 独立成篇（论文 2） | 并入 P1，作为诊断的另一个维度 |
| 修复手段 | 只在 A 的进阶部分（LoRA）和 C 里出现 | 单独成篇（P2） |
| C（强化学习） | 与「基础模型 + 工具」和 API 模型比较 | 与 P2 最好的修法正面比较 |
| 诊断指标 | 正确率、退回旧版率、数值指纹、混用率；B 的三类错误 | 加上先导实验中发现的新失败类型（见 1.4） |

**为什么改（先导实验，见 `pilot_2026-09-23.md`）：**

1. **A 单独成篇的前提不成立。**
   - 真实人群中新旧结论相反的只有 5.7%（14/244），v1 假设至少 15%；
   - PCE / PREVENT 中位比值 1.11，不是 v1 假设的约 2 倍，「数值指纹」在中小模型上分辨不出公式；
   - 最强的 gpt-6-astra 在冲突病例上 97% 正确，基本不退回旧版；明确把新规则当笔误的只有 Qwen 8B 思考模式。
2. **v2 的前提得到支持。** 不同大小的模型卡在不同环节，同一种修法只修得好一部分：直接给出风险值后，8B、14B、gpt-6-sol 在 A 上的错误全部消失，1.7B 的却修不好。
3. **A 和 B 有共同的失败类型。** 「以为缺了其实不需要的输入」在 A（astra 声称缺 BMI）和 B（14B 过度弃权）里都出现，所以放进同一套诊断更合适。

**保留的退路：** 如果正式实验中前沿模型的推理模式出现很强的「会算但仍选旧规则」，A 仍可单独成篇。

  train/         P3 的 SFT 与 GRPO

### 0.3 原则

- **标准答案只由程序产生。** 不用大模型当评委，不做人工标注。
- **先导与正式分开。** 先导用过的 NHANES 病人记在 `pilot/out/pilot_seqns.txt`，正式实验排除。
- **提示冻结后才跑正式实验**，正式数据只跑一次。
- **重复采样与多种写法。** 每个病例每个条件至少 3 次采样、至少 2 种写法；报告重复之间的噪声作为基线。先导大多只问一次、一种写法，这是先导结论最主要的局限。
- **数据合规。** NHANES 可以发给 API；MIMIC 只在本机（M4 Max）跑开源模型，不上任何外部 API（PhysioNet 数据协议）；发表时按协议公开代码。
- **缺数据绝不当低风险。** 必需输入缺失或超出公式适用范围时，程序返回「无法计算」。

## P1. 诊断：模型在哪个环节出错

### 1.1 研究问题

- **RQ1.1** 执行「要不要开药」这条规则时，各环节（选规则、算风险、下结论、判断能否下结论）的错误率是多少？
- **RQ1.2** 错误随模型大小、推理模式怎么变？不同大小的模型是不是卡在不同环节？
- **RQ1.3** 模型说的和做的一致吗？自称用了哪个公式、哪个阈值，和它报出的数值是否对得上？
- **RQ1.4** 指南更新时，模型会不会退回旧版？以什么形式退回：明说旧规则、把新规则当笔误、新阈值配旧公式、以旧公式为参照，还是静默替换？
- **RQ1.5** 信息不全时，模型能否分辨「一定开 / 一定不开 / 无法判断」？过早下结论和过度弃权各占多少？错误和「风险区间离阈值多远」有什么关系？
- **RQ1.6** 模型会不会声称缺了其实不需要的输入？这个现象在 A 类和 B 类任务里是不是同一种失败？

### 1.2 研究价值

1. **对大模型研究：** 现有医学大模型评测大多只报一个总分，而且靠医生或大模型打分。这里每个环节都有程序算出的标准答案，可以把错误精确定位，并且完全可复现。
2. **能看见「看起来对、其实没做」的错误。** 先导中：1.7B 自称用 PREVENT，报的数值和真实值毫无关系；8B、14B 接受新阈值却自称用旧公式。这类错误从最终答案上看不出来。
3. **方法可推广：** 任何「规则明确、会更新、需要计算」的领域都适用，如税务、保险、合规。

### 1.3 病例与条件

**病例集**

| 病例类型 | 来源 | 用途 | 先导中的问题与改进 |
|---|---|---|---|
| 冲突病例 | NHANES：40–79 岁、1 期、无心血管病 / 糖尿病 / CKD、未服降压药，两版决定相反 | 规则选择 | 先导只有 14 个真实病例、36 个合成病例 → 合并更多 NHANES 周期；合成病例单独报告 |
| **贴近阈值的一致病例**（新增，必需） | 同上人群中，两版决定相同、但 PREVENT 离 7.5% 不到 1.5 个百分点 | 冲突病例的对照 | 先导没有这个对照，分不清「退回旧版」和「贴近阈值时的随机算错」 |
| 远离阈值的一致病例 | 同上 | 基本功 | — |
| 信息不全病例 | NHANES 30–79 岁，隐去血脂（再扩展到隐去糖尿病、eGFR） | 能否下结论 | 按三类答案和「离阈值距离」分层抽样 |
| 真实病历分支 | MIMIC 出院小结 + 结构化年龄、性别、门诊血压（只在本机） | 外部效度、编造率 | 可行性已查：血脂 3/50 写在小结里，隐去血脂后 τ = 7.5% 时 61.8% 可判定 |

人群占比一律按真实病例报告（先导：冲突 5.7%）。

**条件**（每个条件只改一件事，读的是条件之间的差）

| 代号 | 给模型什么 | 拆出哪个环节 |
|---|---|---|
| C0 | 只说「按现行美国指南」 | 默认用哪一版 |
| C1 | 明确写出 2025 规则 | 端到端表现 |
| C1+risk | C1 + 算好的 PREVENT 值 | 去掉「算」这一步 → C1+risk − C1 = 算错造成的损失 |
| **C1+both**（新增） | C1 + PCE 和 PREVENT 两个数值 | 只剩「选规则」这一步；直接测规则选择 |
| **C1+inputs**（新增） | C1 + 写明公式需要哪些输入、BMI 不需要 | 「声称缺输入」是否消失 |
| C5 | 明确写出 2017 规则 | 反向对照：会不会用旧规则 |
| B-direct | 2025 规则 + 隐去血脂 | 端到端能否下结论 |
| B+range | B-direct + 风险可能落在的区间 | 去掉「算区间」 → 只剩判断逻辑 |
| B-NS | 模型只抽取、由程序判定 | 剩下的错误只来自抽取 |

v1 的「贴指南原文」和「RAG」两个条件移到 P2，作为修法比较。

### 1.4 指标与失败类型

| 类别 | 指标 | 定义 | 先导中见到的 |
|---|---|---|---|
| 主指标 | 决定正确率 | 按所要求规则的决定，冲突病例、贴近阈值的一致病例、远离阈值的一致病例分开报 | — |
| 选规则 | 阈值正确率；自称的公式 | 报的阈值是否等于所要求的；公式名归为 PREVENT / PCE 类 / 其他 | 8B 自称 Framingham、14B 自称 ASCVD 计算器 |
| 算风险 | 误差、相关 | 报出值与真实值的误差中位数、±1 个百分点以内的比例、相关系数 | 8B 相关系数 −0.05；astra 误差 0.02 个百分点 |
| 下结论 | 自洽性 | 决定是否与自己报的数值和阈值一致 | 1.7B 给了数值仍矛盾 |
| 说到做到 | 数值指纹、静默替换 | 报出值更接近哪个公式；自称用 PREVENT、数值却是 PCE 值（离 PCE ≤0.1 且离 PREVENT >1 个百分点） | astra 约 1%，重复采样未复现 |
| 退回旧版 | 当笔误、以旧公式为参照 | 推理文本里把新规则称为笔误或占位符；先估旧公式再调整 | 8B 思考；gpt-6-sol 26% 的摘要 |
| 能否下结论 | 三分类准确率、过早下结论率、过度弃权率、方向判反率 | 按区间运算的标准答案 | 1.7B 从不弃权；14B 59/60 弃权 |
| 缺输入 | 声称缺不需要的输入 | 以某输入缺失为由不算或不答，而该输入不在公式里 | astra 7/149 声称缺 BMI |
| 真实病历 | 编造率 | 报出的数值在病历里不存在 | 待测 |

推理文本的判定（当笔误、以旧公式为参照）先用关键词粗筛，再人工逐条确认；前沿模型只能看推理摘要，这类结论以开源模型为主。

### 1.5 模型

- **本机：** Qwen3 0.6B / 1.7B / 4B / 8B / 14B，非思考和思考两种模式；更大的模型用 4-bit 量化或放到集群。
- **API：** OpenAI 2–3 个模型（至少一个推理型），推理强度 medium；Anthropic 模型（如获研究额度）。
- 每个模型的训练截止时间写入附表。

### 1.6 统计

- 各环节错误率用自助法算置信区间（按病人重抽样）。
- 混合效应逻辑回归：因变量为「决定是否正确」；固定效应为条件、模型大小、两者交互、离阈值距离；病人和写法作随机效应。
- 条件两两比较用 McNemar 检验；多重比较校正。
- 先导数据做功效分析，确定每类病例的数量。

### 1.7 预期结果（假设）

| 假设 | 预期（依据先导） | 如果相反，说明什么 |
|---|---|---|
| H1.1 | 中小模型的主要错误在「算风险」；给出数值后大部分消失 | 规则理解才是瓶颈 |
| H1.2 | 最小的模型还有「下结论与自己数字矛盾」，给数值也修不好 | 小模型的问题同样只是计算 |
| H1.3 | 「退回旧版」随模型变强而减弱，形式从明说旧规则、当笔误，变为以旧公式为参照 | 前沿模型也系统性退回旧版 → A 可单独成篇 |
| H1.4 | 加入贴近阈值的对照后，中档模型的「退回旧版」大部分可以用随机误差解释 | 确实存在向 PCE 偏的系统偏差 |
| H1.5 | 小模型过早下结论，大模型过度弃权 | 两类错误与规模无关 |
| H1.6 | 「声称缺输入」在 A、B 两类任务里同时出现，且写明所需输入后减少 | 两者是不同机制 |

### 1.8 工作量与止损

- 测试台（合并 NHANES 周期、新增对照病例和条件、多写法、Batch runner）：1 个月。
- 正式运行与分析：2–3 个月。
- **止损：** 如果加入对照后，所有失败类型都只剩「算不准」一种，P1 收窄为「计算错误如何从答案表面隐藏」，P2 的重点随之改为计算工具和训练。

## P2. 干预阶梯：哪种修法修好哪类错误

### 2.1 研究问题

- **RQ2.1** 每种修法修好了 P1 中的哪几类错误？有没有引入新错误？
- **RQ2.2** 代价如何：token、调用次数、训练算力、对其他能力的损害？
- **RQ2.3** 修好的效果能否迁移：换一批病人、换一种写法、换一个公式（PCE ↔ PREVENT）、换到真实病历？
- **RQ2.4** 提示能压住的，是不是就不必改权重？知识编辑能不能改「阈值是 10%」这类程序性规则，还是只能改事实？

### 2.2 修法阶梯

| 层级 | 修法 | 改不改模型 | 适用 | 预计主要修好 |
|---|---|---|---|---|
| 1 | 手写提示：明确指令、对比提示（「2025 版与 2017 版的区别是……」）、先写出公式再作答 | 不改 | 所有模型 | 新阈值配旧公式 |
| 2 | 少样本例题（附完整计算过程） | 不改 | 所有模型 | 计算、格式 |
| 3 | 贴指南原文 / RAG 检索（原 v1 的 C2、C3） | 不改 | 所有模型 | 规则选择；检验长文本是否稀释新规则 |
| 4 | 自动提示优化（DSPy、OPRO 一类），以程序算出的正确率为目标 | 不改 | 所有模型 | 同 1，看能否自动找到 |
| 5 | 多次采样投票 | 不改 | 所有模型 | 随机算错 |
| 6 | 计算工具 / 只抽取、程序判定 | 不改 | 所有模型 | 算不准（先导已证实） |
| 7 | 解码时干预（增强对上下文的依赖）、激活引导 | 不改权重，需访问内部 | 开源 | 退回旧版 |
| 8 | Soft prompt 调优 | 训练一小段向量 | 开源 | 规则选择 |
| 9 | LoRA 微调，训练数据由程序生成 | 训练附加参数 | 开源 | 规则选择、计算 |
| 10 | 知识编辑（ROME / MEMIT 一类） | 定点改权重 | 开源 | 退回旧版 |

1–6 可用于前沿模型；7–10 在本机的 Qwen 上做，基本不花 API 费用。各层对应的文献已补进文献地图（「干预阶梯」主题，标 P2，核验到摘要），正文引用前仍需读原文。

### 2.3 方法

- **评测：** 全部用 P1 的指标和病例集；每种修法在同一批测试病人上报告各类错误的变化，而不是只报总分。
- **防过拟合：** 修法用开发集病人调，在测试集病人上报告；另设三个迁移集：新写法、另一个公式、真实病历（本机）。
- **能力损失：** 训练类修法（8–10）在 MedQA 子集和一个通用基准上测能力变化。
- **代价：** 记录 token、调用次数、GPU 小时、费用，画出「修好的错误 vs 代价」的前沿。

### 2.4 预期结果（假设）

| 假设 | 预期 |
|---|---|
| H2.1 | 计算工具修好「算不准」，但修不好「结论与自己数字矛盾」和「过度弃权」 |
| H2.2 | 对比提示能压住中档模型的「新阈值配旧公式」；最小的模型需要改权重 |
| H2.3 | 贴长篇原文或 RAG 比一句指令差，因为新规则被长文本稀释 |
| H2.4 | 知识编辑能改掉阈值，但对换一种写法的迁移较差 |
| H2.5 | 训练类修法在同分布上效果好，换写法和换公式后明显缩水 |

### 2.5 工作量与止损

- 3 个月，大部分在本机。
- **止损：** 训练类修法（8–10）在 300 个训练样本内对任何错误类型都没有改善，就只报告不改模型的修法 1–6，训练部分并入 P3。

## P3. 强化学习：训练能否修得更彻底

### 3.1 研究问题

- **RQ3.1** 用程序给分的强化学习（GRPO）训练 1.5–4B 的 Qwen，在 P1 的各类错误上能否超过 P2 最好的修法？能否接近前沿模型？
- **RQ3.2** 学到的东西能否迁移：新写法、新的缺失模式、另一个公式、真实 MIMIC 病历？
- **RQ3.3** 提升来自真正的计算和判断能力，还是只是格式更规整、失误更少？

### 3.2 方法

- **基础模型：** Qwen2.5-1.5B-Instruct、Qwen3-1.7B / 4B。
- **热启动：** 约 2,000 条由程序模板生成的解题过程（不用大模型生成）。
- **GRPO：** TRL 的 GRPOTrainer + LoRA；每组 8 个样本，最大长度 1,024；先跑 300 步先导。
- **奖励（全部由程序给出，权重在先导阶段定好后冻结）：** JSON 合法；决定正确；风险值误差 ±1 个百分点以内（软奖励）；能否判定正确；声称缺不需要的输入扣分；超长扣分。
- **数据划分：** 按病人划分；同分布测试 + 四个迁移集（新写法、新缺失模式、另一个公式、MIMIC 本机）。
- **对照：** 未训练的基础模型；仅 SFT；SFT + GRPO；**P2 最好的修法**；前沿模型。
- **区分能力还是格式：** 训练前后各类错误的分布；只换输出格式后提升是否保留；可选的隐藏层探针（内部能否读出风险值）。

### 3.3 预期结果（假设）

| 假设 | 预期 |
|---|---|
| H3.1 | 同分布大幅提升，其中很大一部分来自格式和算术失误的减少 |
| H3.2 | 迁移集的提升明显小于同分布，真实病历上最小 |
| H3.3 | 「小模型 + 计算工具」可能接近 GRPO；若成立，结论是「给工具比训练划算」 |
| H3.4 | 奖励里的「缺输入扣分」能减少过度弃权，但可能增加过早下结论 |

### 3.4 工作量与止损

- 5 个月；需要 CUDA GPU（Colab Pro/Pro+ 或学校集群）。
- **止损：** 300 步先导内同分布没有提升或训练不稳定，就改为只做 SFT 对比，并入 P2。

## 6. 风险与对策

| 风险 | 对策 |
|---|---|
| 前沿模型已基本算对，效应太小 | 诊断重点放在中小模型和开源模型；前沿模型上研究剩下的新失败类型（如声称缺输入） |
| 冲突病例太少 | 合并多个 NHANES 周期；合成病例单独报告；占比按真实数据报告 |
| 看不到前沿模型的原始推理 | 推理过程相关的结论以开源模型为主；前沿模型只看输出 |
| 成本和算力 | Batch API、子集重复采样、研究额度、学校集群 |
| MIMIC 合规 | 只在本机跑开源模型；发表时公开代码 |
| PCE 系数录入错误 | 正式实验前第二人对照 Goff 2013 表 A 核对（不需要临床判断） |
| 规则转写涉及临床理解 | 本项目只用已发表的公式和阈值；如需把更多指南条文编进测试台，请有临床背景的人复核 |
