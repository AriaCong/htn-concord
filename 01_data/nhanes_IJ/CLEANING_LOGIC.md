# NHANES I+J 数据清理逻辑

状态：2026-10-20 经确认后按本文执行。结果见 `README.md`。

日期：2026-10-20。范围：NHANES 2015–2016（I）和 2017–2018（J）两个周期。L 不参与，P 不使用（P 与 J 是同一批人，只是 SEQN 不同）。

## 0. 总原则

1. 原始文件只读。`01_data/raw/NHANES/` 和 `01_data/raw/NHANES_I/` 不写入任何东西；每个用到的文件都记录 SHA256，运行结束时再核对一次。
2. 分三层输出，互不覆盖：
   - **原值表**：XPT 里的值，一个不改；
   - **派生表**：所有计算、校准和跳题还原的结果；
   - **分析集**：经过筛选的人。
3. 不填补缺失，不截断异常值，不删除记录。被排除的人仍然保留在原值表中，并记录排除原因。
4. 每个派生字段都写明输入、规则和在什么情况下保持“未知”。

## 1. 读取

1. 用 `pandas.read_sas(format="xport")` 读取 XPT。
2. **还原 0 值**：pandas 会把 SAS 的 0 读成 5.397605346934028e-79。读取后把绝对值小于 1e-70 且不等于 0 的值还原为 0，并按列记录还原数量。这是修正读取错误，不算改值。
3. SEQN 转成整数。

## 2. 表的结构与合并

| 类型 | 表 | 处理 |
| :--- | :--- | :--- |
| 一人一行 | DEMO、BPX、BIOPRO、TCHOL、HDL、GHB、ALB_CR、BMX、BPQ、DIQ、SMQ、MCQ；BPXO（只有 J） | 每个周期以 DEMO 为母表，按 SEQN 一对一左连接 |
| 一人多行 | RXQ_RX | 保留原始长表；在派生表里汇总为每人一个他汀判断 |
| 词典 | RXQ_DRUG | 只保留原样，作参考 |

- 每次合并都检查：SEQN 唯一、行数不变、已有列的值不变、合并进来的表的所有 SEQN 都在 DEMO 里。
- 两个周期上下堆叠，加一列 `cycle`。列名使用不带周期后缀的前缀，例如 `DEMO__RIDAGEYR`。
- 检查两个周期 SEQN 不重叠，抽样分层编号也不重叠。
- **缺失原因分三类**：
  - 该周期没有这个组件（I 没有 BPXO）；
  - 这个人不在该组件里（例如没去体检、没抽血）；
  - 人在组件里，但这个格子是空的（跳题或未回答）。

## 3. 派生字段

### 3.1 测量值

| 字段 | 规则 |
| :--- | :--- |
| `sbp_mean`（主要指标） | 听诊 BPXSY1–4 中大于 0 的读数取平均，不四舍五入，不丢弃第 1 次读数 |
| `dbp_mean` | 听诊 BPXDI1–4 中大于 0 的读数取平均；DBP=0 是原记录，保留在原值表，但不计入平均（我做的判断，见第 6 节） |
| `sbp_mean_oscillometric_J_only` | J 的示波血压，仅用于敏感性分析 |
| `creatinine_J_scale` | J 不变；I = 0.9515 × LBXSCR + 0.06608（CDC 在 BIOPRO_J 中给出的 Deming 方程） |
| `egfr` | CKD-EPI 2021 肌酐方程（无种族项），使用 `creatinine_J_scale`；年龄小于 18 或为 80（顶码）时为缺失 |
| `non_hdl` | LBXTC − LBDHDD |
| `wt*_pooled` | WTINT2YR、WTMEC2YR ÷ 2 |

### 3.3 其他问卷与药物判断（规则与上一轮相同）

- **糖尿病 `diabetes`**：DIQ010=1 → 是；DIQ010=2 → 否；DIQ010=3（临界）→ 未知，不当作否；7/9 → 未知。HbA1c ≥6.5 另存为独立的筛查证据，不并入诊断。
- **心血管病史 `cvd_history`**：MCQ160B–F 任意一项 = 1 → 有；五项全部 = 2 → 无；其余 → 未知。
- **他汀 `statin`**：RXDUSE=2（过去 30 天没用处方药）→ 否；有成分名明确为他汀的药物 → 是；全部药名都能识别且没有他汀 → 否；有药名无法识别 → 未知。按成分词匹配，不做子串粗匹配。

## 4. 分析集筛选（顺序执行，每一步都记录人数和每人的排除原因）

1. 年龄 30–79 岁（PREVENT 适用范围）。
2. `cvd_history` = 无（一级预防人群）。
3. 已测得的 TC 在 130–320、HDL 在 20–100、SBP 在 90–200、eGFR 在 15–150 之内（PREVENT S12A 定义域）。缺失不算越界。
4. 排除 RIDEXPRG = 1（明确妊娠）。

通过筛选的人分成两组：

- **complete**：十项输入（年龄、性别、TC、HDL、SBP、eGFR、糖尿病、降压药、吸烟、他汀）全部明确，可以直接计算 PREVENT；
- **incomplete**：至少一项未知，保留下来，例如可用于 RQ-B（可判定性研究）。

## 5. 验证（任何一项失败，运行就停止）

- 源文件 SHA256 不变；
- CSV 写出再读回，每个值和每个缺失位置都一致；
- 原值表与 XPT 一致（0 值还原之外没有任何差异），且没有残留的 5.4e-79；
- 肌酐方程只作用于 I 周期；
- 权重正好减半，加权人口总数守恒；
- 跳题还原只用在规则表列出的情况，直接回答从不被覆盖；
- complete 组的十项输入全部不为空。

## 6. 我做的判断（不是数据本身决定的，需要你知道）

1. **听诊 DBP=0 不计入 DBP 平均值**。PREVENT 只用 SBP，所以不影响风险计算。
2. **糖尿病“临界”记为未知**。这是沿用上一轮你选的“临界不当作否”。代价是这些人会落到 incomplete 组。
3. **超出 S12A 定义域的人从分析集中排除**，而不是截断到边界值。
