大模型执行临床规则时，错在哪一环、用什么修

研究对象是大模型本身，心血管风险规则只是试验台。三篇论文前后衔接：先诊断模型在哪个环节出错（P1），再比较各种修法各修好哪类错误（P2），最后看强化学习能否修得更彻底（P3）。所有标准答案都由公式、阈值和区间运算算出，不需要医生裁定。

为什么是这个题目

已发表的心血管 / 高血压大模型研究，大多停在「这个模型在这个任务上得多少分」，而且靠医生或另一个大模型打分。总分说不清错在哪一步，也就不知道该怎么修。

心血管风险决策的核心逻辑是已发表的公式加阈值。例如 2025 版指南规定，1 期高血压且 PREVENT 10 年风险 ≥7.5% 就开药。所以每一个环节都有程序算出的唯一答案，可以把错误精确定位：

选规则

2017 版（PCE ≥10%）与 2025 版（PREVENT ≥7.5%）同时存在于模型的记忆和上下文里。

算风险

PCE 和 PREVENT 都已照原文实现，并与原文算例逐位核对。

下结论与说到做到

决定是否与自己报的数值一致；自称的公式是否就是实际用的公式。

能否下结论

缺胆固醇时，风险区间是否跨过阈值，由区间运算精确算出。

设计原则

  • 标准答案只由程序产生。不用大模型当评委，也不做人工标注。
  • 先导与正式分开。先导用过的病人已记录并排除；提示冻结后正式数据只跑一次。
  • 每例至少 3 次采样、至少 2 种写法，报告重复噪声基线。先导大多只问一次、一种写法，这是先导结论最主要的局限。
  • 缺数据绝不当低风险。必需输入缺失或超出公式范围时返回「无法计算」。

数据流与合规边界

两类数据走不同的路径：公开数据可以去任何地方；受控数据只在本机处理。2026-09-23 已按 PhysioNet 原文核对。

P1

诊断：模型在哪个环节出错

  1. 各环节（选规则、算风险、下结论、判断能否下结论）的错误率是多少？
  2. 错误随模型大小、推理模式怎么变？不同大小的模型是不是卡在不同环节？
  3. 模型说的和做的一致吗？自称的公式、阈值和它报出的数值是否对得上？
  4. 指南更新时会不会退回旧版？以什么形式：明说旧规则、当笔误、新阈值配旧公式、以旧公式为参照、静默替换？
  5. 信息不全时能否分辨「一定开 / 一定不开 / 无法判断」？错误和「离阈值多远」有什么关系？
  6. 会不会声称缺了其实不需要的输入？A、B 两类任务里是不是同一种失败？

实验条件（每个只改一件事，读条件之间的差）

代号给模型什么拆出哪个环节
C0只说「按现行美国指南」默认用哪一版
C1明确写出 2025 规则端到端
C1+risk再给算好的 PREVENT 值去掉「算」：C1+risk − C1 = 算错造成的损失
C1+both 新同时给 PCE 和 PREVENT 两个数值只剩「选规则」
C1+inputs 新写明公式需要哪些输入、BMI 不需要「声称缺输入」是否消失
C5明确写出 2017 规则反向对照
B-direct2025 规则 + 隐去血脂端到端能否下结论
B+range再给风险可能落在的区间只剩判断逻辑
B-NS模型只抽取、由程序判定剩下的错误只来自抽取

病例

  • 冲突病例：40–79 岁、1 期、无心血管病 / 糖尿病 / CKD、未服药，两版决定相反。合并多个 NHANES 周期；合成病例单独报告。
  • 贴近阈值的一致病例（新增，必需）：PREVENT 离 7.5% 不到 1.5 个百分点但两版决定相同，用来区分「退回旧版」和「随机算错」。
  • 信息不全病例：隐去血脂（再扩展到糖尿病、eGFR），按三类答案和离阈值距离分层抽样。
  • 真实病历分支（本机）：MIMIC 出院小结 + 结构化字段，测编造率。

失败类型（先导中已见到的）

失败类型先导中出现在
算不准风险所有模型；给出数值后 8B、14B、sol 全部修好
结论与自己的数字矛盾1.7B
新阈值配旧公式名8B（Framingham）、14B（ASCVD 计算器）
把新规则当笔误8B 思考模式（57/80 自称 PCE）
以旧公式为参照gpt-6-sol（26% 的推理摘要，偏差较弱）
静默替换gpt-6-astra 约 1%，重复采样未复现
声称缺不需要的输入gpt-6-astra 4.7%（BMI）
过早下结论 / 过度弃权1.7B 从不弃权；14B 59/60 弃权

预期结果（假设）

  • 中小模型的主要错误在「算风险」；最小的模型另有「结论与数字矛盾」。
  • 「退回旧版」随模型变强而减弱，形式从当笔误变为以旧公式为参照；加入贴近阈值的对照后，中档模型的大部分「退回旧版」可以用随机误差解释。
  • 小模型过早下结论，大模型过度弃权；「声称缺输入」在写明所需输入后减少。
P2

干预阶梯：哪种修法修好哪类错误

  1. 每种修法修好了 P1 中的哪几类错误？有没有引入新错误？
  2. 代价如何：token、调用次数、训练算力、对其他能力的损害？
  3. 效果能否迁移：换一批病人、换一种写法、换一个公式、换到真实病历？
  4. 提示能压住的，是不是就不必改权重？知识编辑能不能改「阈值是 10%」这类程序性规则？
层级修法改模型？预计主要修好
1手写提示：明确指令、对比新旧版、先写公式再作答不改新阈值配旧公式
2少样本例题不改计算、格式
3贴指南原文 / RAG（v1 的 C2、C3）不改规则选择；长文本是否稀释新规则
4自动提示优化，以程序算出的正确率为目标不改同 1，看能否自动找到
5多次采样投票不改随机算错
6计算工具 / 只抽取、程序判定不改算不准（先导已证实）
7解码时干预、激活引导需访问模型内部退回旧版
8Soft prompt 调优训练一小段向量规则选择
9LoRA 微调，数据由程序生成训练附加参数规则选择、计算
10知识编辑（ROME / MEMIT 一类）定点改权重退回旧版

1–6 可用于前沿模型；7–10 在本机的 Qwen 上做，基本不花 API 费用。各层对应的文献已补进文献地图（标 P2，核验到摘要）。评测一律用 P1 的指标，在开发集调、测试集报，并设新写法、另一个公式、真实病历三个迁移集。

预期结果（假设）

  • 计算工具修好「算不准」，但修不好「结论与数字矛盾」和「过度弃权」。
  • 对比提示能压住中档模型的「新阈值配旧公式」；最小的模型需要改权重。
  • 训练类修法在同分布上效果好，换写法和换公式后明显缩水。
P3

强化学习：训练能否修得更彻底

  1. 用程序给分的强化学习（GRPO）训练 1.5–4B 的 Qwen，能否超过 P2 最好的修法、接近前沿模型？
  2. 能否迁移到新写法、新缺失模式、另一个公式、真实 MIMIC 病历？
  3. 提升来自真正的能力，还是只是格式更规整、失误更少？
  • 模型：Qwen2.5-1.5B-Instruct、Qwen3-1.7B / 4B；约 2,000 条程序生成的解题过程做热启动；TRL GRPO + LoRA。
  • 奖励（全部由程序给出）：JSON 合法；决定正确；风险值误差 ±1 个百分点以内；能否判定正确；声称缺不需要的输入扣分（新增）；超长扣分。
  • 对照：未训练的基础模型；仅 SFT；SFT + GRPO；P2 最好的修法；前沿模型。
  • 区分能力还是格式：训练前后各类错误的分布；只换输出格式后提升是否保留；可选的隐藏层探针。

预期结果（假设）

  • 同分布大幅提升，其中很大一部分来自格式和算术失误的减少；迁移集提升明显更小，真实病历上最小。
  • 「小模型 + 计算工具」可能接近 GRPO；若成立，结论是「给工具比训练划算」。

约束与风险

数据合规（2026-09-23 已查 PhysioNet 原文）：数据使用协议禁止把 MIMIC 发给第三方 API（明确点名 OpenAI 和 ChatGPT）。PhysioNet 2025 年的指引强烈建议使用本地部署的模型。因此 MIMIC 只在本机（M4 Max）跑开源模型；API 只用于 NHANES；P3 的训练数据来自 NHANES，可以在 Colab 上训练，训练好的模型拿回本机测 MIMIC。协议第 9 条：公开发表结果时，必须同时公开产生这些结果的代码。
风险应对
前沿模型已基本算对，效应太小诊断重点放在中小模型和开源模型；前沿模型上研究剩下的新失败类型（如声称缺输入）
冲突病例太少合并多个 NHANES 周期；合成病例单独报告；占比按真实数据报告
看不到前沿模型的原始推理推理过程相关的结论以开源模型为主；前沿模型只看输出
成本和算力Batch API、子集重复采样、研究额度、学校集群；训练每步存检查点
PCE 系数录入错误原文算例已一致；正式实验前第二人对照 Goff 2013 表 A 核对
规则转写涉及临床理解只用已发表的公式和阈值；如需编入更多指南条文，请有临床背景的人复核

开始之前需要确认

  1. 与导师确认转向：从 HTN-Concord 转到本方向，还是两者并行。
  2. API 与 GPU 预算；学校有没有 GPU 集群。
  3. 申请 Anthropic、OpenAI 研究额度。
  4. PCE 系数第二人核对。
