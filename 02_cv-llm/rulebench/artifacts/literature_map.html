大模型执行可计算临床规则：相关研究全景

这张地图服务三个研究问题：A 指南更新时模型听上下文还是听记忆；B 信息不全时模型知不知道能否下结论；C 能否用程序打分的强化学习训练本地小模型；以及方案 v2 新增的 P2 干预阶梯：哪种修法修好哪类错误。每条文献列出它做了什么、用什么方法和数据、用什么架构、得出什么结论，以及和本项目的关系。

各研究问题的空位

每张卡片列出最接近的前作，以及检索后仍然空着的部分。「仍空」是指在本轮检索范围内没有找到，不等于穷尽。

RQ-A · 知识冲突

指南更新后，模型会不会悄悄沿用旧规则

最接近的前作
  • TempoMed-Bench：选择题，考察新旧推荐的回忆
  • DriftMedQA：人工构造的「伪过时」推荐
  • MedCounterFact：模型几乎无条件接受上下文里的假证据
  • Adaptive Chameleon：通用领域的事实型知识冲突
  • GuideBench：规则更新后的鲁棒性，非医学

仍空病人层面、新旧两版都真实存在、结论可以由程序算出的程序性规则冲突（PCE ≥10% 对 PREVENT ≥7.5%）；用数值指纹识别模型实际在用哪个方程；「新阈值配旧方程」的混用。

RQ-B · 可判定性

缺数据时，模型知不知道结论其实已经确定

最接近的前作
  • ClinDet-Bench：94 个人造病例、计分式量表
  • MedAbstain：选择题改造成弃权题
  • When Confidence Fails：置信度对信息缺失不敏感
  • SCORE2 基准：抽取好、计算差，但没有测弃权
  • 语义熵、P(True)：通用不确定性方法

仍空连续方程 + 区间运算给出的精确可判定性标签；按「区间到阈值的距离」连续控制难度；真实病历里的自然缺失，以及模型编造缺失数值的比例。

RQ-C · 可验证奖励 RL

程序打分的强化学习，能不能把这些能力训练进小模型

最接近的前作
  • HuatuoGPT-o1：医学可验证问题 + 验证器奖励
  • MedCalc-R1：奖励里仍用了 LLM 评委
  • Yue 2025：RLVR 提高采样效率，但不扩展能力边界
  • 精神科轻量模型 RL：Qwen3 0.6–8B + LoRA
  • AgentMD / npj 工具研究：给工具就能大幅减错

仍空心血管方程上完全由程序给分的 RL；从模板病例迁移到真实病历、迁移到新方程的泛化；区分「学会计算」和「学会格式」；和「小模型 + 工具」的正面对比。

P2 · 干预阶梯（方案 v2）

哪种修法修好哪类错误、代价多大、能否迁移

最接近的前作
  • 自动提示优化（APE、OPRO、DSPy / MIPRO）：只报总分提升；临床上已有 DSPy 用于电子病历问答
  • 工具与程序计算（PAL、PoT）：算术错误大幅减少
  • 上下文感知解码：能压住与上下文冲突的先验知识
  • 知识编辑（ROME、MEMIT）：医学上只停留在表面记忆（MedEditBench）；规则层面的编辑刚起步
  • 微调注入新知识会增加编造（Gekhman 2024）

仍空在同一个测试台、同一套分环节指标上，把提示、优化、工具、解码干预、软提示、LoRA、知识编辑放在一起比较，报告每种修法修好了哪类错误、代价多大、换病人或换写法后还剩多少；知识编辑能否改写临床公式和阈值这类程序性规则。
